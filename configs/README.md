# configs: experiment settings

`experiment.json` controls image/keypoint budgets, SIFT parameters, descriptor normalization, ratio-test threshold, and MMA scoring. `hpatches_source.json` records the dataset mirror and downloaded archive hash.

The current configuration uses shared OpenCV RootSIFT descriptors for A/B. Validate changes on the train split and freeze settings before evaluating the 20-sequence test split. Pixel thresholds are measured after resizing; zero-match pairs score zero. These files are inputs and are not regenerated by evaluation.
